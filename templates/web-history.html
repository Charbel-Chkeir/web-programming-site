Introduction

The history of the World Wide Web is a remarkable chronicle of how global communication, information sharing, and human connectivity were completely transformed. While the underlying infrastructure of the Internet had been developing for decades, the Web itself was born in 1989 when British scientist Tim Berners-Lee submitted his visionary proposal for a linked hypertext information system while working at CERN. By late 1990, he had successfully built the first web server, browser, and website, establishing the core framework of HTTP, HTML, and URIs. When CERN placed the web software into the public domain in 1993, it unleashed an explosive wave of global innovation. From early graphical browsers and the dot-com boom to modern mobile ecosystems and web applications, the Web swiftly evolved from an academic tool into an indispensable fabric of daily modern society.

Key Milestones (1989 – 2008)

1989: The Web Proposed

Tim Berners-Lee submitted his initial proposal at CERN for a distributed hypertext system called the World Wide Web to help researchers share information seamlessly.

Source: CERN

1990: First Server and Browser

Berners-Lee successfully created the world's first web server, browser/editor, and website (info.cern.ch) running on a NeXT computer at CERN, proving the concept worked.

Source: CERN Timeline

1991: Public Announcement

Berners-Lee announced the WWW software on Internet newsgroups, making it publicly available outside CERN and allowing the first external web server to launch at Stanford.

Source: W3C History

1993: Public Domain Release & Mosaic

CERN officially released the World Wide Web software into the public domain on a royalty-free basis, while NCSA released the Mosaic browser, triggering massive public adoption.

Source: CERN

1994: Founding of the W3C

Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT to guide open web standards, and the First International WWW Conference was held at CERN.

Source: W3C Consortium

1995: HTML 2.0 & E-Commerce

HTML 2.0 was standardized, e-commerce pioneers like Amazon and eBay expanded, and the Apache HTTP Server project launched, rapidly accelerating commercial web development.

Source: Preceden Timeline

1997: HTML 4.0 & CSS

W3C recommended HTML 4.0 alongside early CSS support, providing powerful styling capabilities that separated document structure from visual design for cleaner web development.

Source: Preceden Timeline

1998: Web Standards Project (WaSP)

Frustrated by inconsistent browser compliance with standards, web designers formed the Web Standards Project (WaSP) to advocate for cross-browser consistency.

Source: Web Foundation History

1999: XMLHttpRequest & Web 2.0

Microsoft introduced the XMLHttpRequest object in Internet Explorer, and the term "Web 2.0" was coined, laying the technical and conceptual foundation for interactive web applications.

Source: Microsoft Learn

2002: Advanced Ajax Webmail

Developers at Oddpost utilized XMLHttpRequest to build the first advanced Ajax webmail client, demonstrating that web apps could match the performance of desktop software.

Source: Wikipedia Ajax

2004: WHATWG & Facebook

The WHATWG was formed by browser vendors to evolve HTML, and Facebook launched, ushering in the era of user-generated content, social networks, and dynamic web applications.

Source: WHATWG

2007: The Mobile Web & iPhone

Apple introduced the iPhone with a full-featured mobile web browser, permanently transforming how billions of users access content and interact with web services on the go.

Source: Apple Newsroom

2008: Google Chrome & V8 Engine

Google released the Chrome browser featuring the high-performance V8 JavaScript engine, dramatically speeding up browser processing capabilities and reshaping client-side web development.

Source: Google Blog

2009: Node.js

Node.js was introduced, allowing developers to execute JavaScript on servers, which unified web development languages and supercharged real-time web application scaling.

Source: Node.js About

2011: Web APIs

Mozilla announced Web APIs to give web applications direct access to hardware components like GPS and cameras, while Chromebooks debuted to champion cloud-first web computing.

Source: MDN Web Docs

Three Key Technologies

  • HTTP (Hypertext Transfer Protocol): The foundational application-layer protocol used across the World Wide Web for distributed, collaborative hypermedia information systems, defining how client browsers request resources and web servers respond with data.
  • HTML (Hypertext Markup Language): The standard markup language used to create and structure documents on the Web, allowing developers to define headings, paragraphs, links, and multimedia elements that browsers render into visual pages.
  • URI / URL (Uniform Resource Identifier / Locator): A compact string of characters that unambiguously identifies and locates unique resources—such as web pages, images, or files—on the decentralized network of the Web.
