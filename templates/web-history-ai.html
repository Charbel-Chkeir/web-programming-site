Introduction

The World Wide Web is a system for accessing and linking information through the Internet. It was invented by Tim Berners-Lee while working at CERN in 1989 as a way for researchers to share information more easily. By 1990, Berners-Lee had developed the first web server and the first web browser/editor, together with the fundamental technologies HTML, HTTP, and URI. During the 1990s, the Web expanded rapidly as browsers became easier to use and organizations such as the World Wide Web Consortium developed open standards to promote interoperability. The Web later evolved from mainly static documents into increasingly interactive applications and services.

Key Milestones (1989 – 2004)

Major milestones in the development of the World Wide Web from 1989 to 2004
Year Milestone Description Verified Source
1989 The World Wide Web Proposed Tim Berners-Lee submitted a proposal at CERN for a distributed hypertext information system. The project was intended to help researchers share and connect information across different computer systems. CERN - The Birth of the Web
1990 First Web Server and Browser Tim Berners-Lee developed the first web server and the first browser/editor, called WorldWideWeb, while working at CERN. The first website was hosted on his NeXT computer and provided information about the World Wide Web project itself. W3C - History
1991 The Web Becomes Publicly Available The World Wide Web project began spreading beyond CERN as its software and documentation were made available to people outside the laboratory. This allowed other institutions to create web servers and participate in the growing Web. CERN - A Short History of the Web
1993 CERN Releases Web Software and Mosaic Appears On April 30, 1993, CERN placed the World Wide Web software in the public domain. In the same period, the graphical Mosaic browser helped make the Web easier to use and contributed to its rapid expansion. CERN - The Birth of the Web
1994 Founding of the World Wide Web Consortium Tim Berners-Lee founded the World Wide Web Consortium (W3C) at MIT in October 1994. The organization was created to coordinate the development of open Web standards and promote compatibility between websites, browsers, and other Web technologies. World Wide Web Consortium (W3C)
1995 Growth of the Commercial Web By the mid-1990s, the Web had expanded rapidly beyond academic and research institutions. Commercial websites and online services became increasingly common as businesses began using the Web to publish information and provide services to users. CERN - A Short History of the Web
1997 HTML 4.0 Becomes a W3C Recommendation In December 1997, the W3C published HTML 4.0 as an official Recommendation. The specification introduced improvements for accessibility, internationalization, forms, tables, scripting, and style-sheet support while promoting greater interoperability across Web platforms. W3C - HTML 4.0 Recommendation History
1998 Web Standards Project The Web Standards Project was created in response to problems caused by inconsistent support for Web standards among browsers. Its goal was to encourage browser developers to implement common Web standards more consistently. W3C - The History of the Web
2004 WHATWG Is Founded The Web Hypertext Application Technology Working Group (WHATWG) was founded in 2004 by individuals from Apple, the Mozilla Foundation, and Opera Software. The group focused on evolving HTML and Web application technologies while maintaining compatibility with existing Web content. WHATWG - Frequently Asked Questions

Three Key Technologies

HTML (Hypertext Markup Language)
The standard markup language used to structure content on the Web. HTML defines elements such as headings, paragraphs, links, images, tables, forms, and other parts of a web document.
HTTP (Hypertext Transfer Protocol)
The application-layer protocol used by web browsers and web servers to request and transfer resources such as HTML documents, images, and other data.
URI / URL (Uniform Resource Identifier / Uniform Resource Locator)
A standardized way of identifying resources on the Web. URLs are commonly used to specify where a resource is located and how it can be accessed.
