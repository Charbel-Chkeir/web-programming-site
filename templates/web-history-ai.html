History of the Web

Introduction

The World Wide Web (often shortened to the Web) is an information space where documents and other web resources are identified by uniform resource identifiers and can be accessed via the Internet. Invented in 1989 by British scientist Tim Berners-Lee at CERN, the Web turned raw internet infrastructure into a graphical, hyperlinked medium accessible to researchers, enterprises, and the general public.

Key Milestones

Major milestones in the development of the World Wide Web from the 1980s to the 2000s
Year Event Why it Mattered Source
1989 Tim Berners-Lee submitted his initial proposal, "Information Management: A Proposal," at CERN. It laid out the foundational architecture for linking decentralized documents through hypertext across a global network. CERN / W3C
1990 The first web server (info.cern.ch) and the first web browser/editor (WorldWideWeb) were successfully created on a NeXT computer. It proved that a functioning hypertext system could operate seamlessly over live internet connections. CERN / Wikipedia
1991 The Web was introduced to the public via internet newsgroups (alt.hypertext). It transformed the project from an internal particle-physics tool into an open, global collaboration. CERN / W3C
1993 Release of NCSA Mosaic; CERN released web source code on a royalty-free basis. Mosaic's user-friendly graphical interface and inline images drove explosive mainstream adoption, while CERN's royalty-free policy assured open standards. CERN
1994 The World Wide Web Consortium (W3C) was founded at MIT/INRIA, led by Tim Berners-Lee. It established formal, interoperable technical standards and guidelines for the long-term evolution of web technologies. CERN / W3C
2000s The rise of Web 2.0, dynamic web applications, and social media platforms. Shifted the web from static document publishing to interactive, user-generated content and collaborative web applications. W3C / CERN

Three Key Technologies for the Web

  • HTML (Hypertext Markup Language): The standard markup language used to structure documents and display content within web browsers.
  • HTTP (Hypertext Transfer Protocol): The foundational application-layer protocol governing data communication and retrieval between web clients and servers.
  • URL / URI (Uniform Resource Locator): A standardized system of globally unique identifiers that specifies the precise location of resources on the web.
